# Traveler's Backpacks Essentials (tbessentials)

Addon for Traveler's Backpack 10.1.39 (NeoForge 1.21.1). Requires Traveler's Backpack.

Upgrades: Anvil, Stonecutter, Smithing Table, Brewing Stand.
Put one in a backpack upgrade slot, then left-click its icon in the backpack screen to open the workstation.

Recipe (all four): workstation block / Blank Upgrade / wooden chest, stacked vertically.

Build: `gradle build` (Java 21). The jar ends up in build/libs/. Put it in mods/ next to Traveler's Backpack.
